# 🚀 프로젝트 협업 및 Git 워크플로우 가이드

이 문서는 **'초시대 가치 교육'** 프로젝트를 안정적이고 효율적으로 관리하기 위한 공통 가이드입니다. 특히 개인 계정과 공동 저장소 사이의 혼동을 방지하고, 작업 내용을 라이브 사이트(`www.chosidae.kr`)에 안전하게 배포하는 방법을 다룹니다.

---

## 1. 💡 협업 핵심 원칙

가장 중요한 것은 **'작업 방식'**과 **'업로드 위치'**의 명확한 구분입니다.

- **개인 계정 사용**: 작업할 때는 반드시 `goodchoisillustration-create` 계정과 이메일(`goodchois.illustration@gmail.com`)을 사용하여 커밋합니다.
- **공동 저장소 푸시**: 작업이 완료되면 사용자님 개인의 저장소가 아닌, 공동 저장소인 [soonleelife/tve-landing](https://github.com/soonleelife/tve-landing) 으로만 푸시(Push)합니다.
- **동기화**: 작업 시작 전에는 항상 공동 저장소의 최신 내용을 내 컴퓨터로 가져오기(Pull) 합니다.

---

## 2. 🔄 표준 작업 프로세스 (4단계)

수정 사항이 생겼을 때 이 순서대로 진행하면 실수를 방지할 수 있습니다.

### Step 1: 최신 소스 가져오기 (Pull)
터미널에서 아래 명령을 실행하여 다른 사람이 수정한 내용이 있는지 확인하고 가져옵니다.
```bash
git pull origin main
```

### Step 2: 작업 및 로컬 검증 (Edit & Check)
1.  내 컴퓨터에서 `index.html`이나 `style.css` 파일을 수정합니다.
2.  **중요**: 깃허브에 올리기 전에, 수정된 `index.html` 파일을 브라우저(Chrome 등)에 드래그하여 **결과를 먼저 확인**합니다.

### Step 3: 저장 및 업로드 (Commit & Push)
만족스러운 결과가 나왔다면 저장소에 기록을 남기고 업로드합니다.
```bash
git add .
git commit -m "수정 내용 요약(예: 연락처 이메일 수정)"
git push origin main
```

### Step 4: 라이브 반영 확인 (Deploy Check)
-   [www.chosidae.kr](https://www.chosidae.kr) 에 접속하여 수정 사항이 1~2분 뒤에 정상적으로 반영되었는지 확인합니다. (배포는 Vercel 시스템에 의해 자동으로 이루어집니다.)

---

## 3. 📂 프로젝트 구조 이해

- **`index.html`**: 홈페이지의 뼈대와 모든 글자가 들어있는 핵심 파일입니다.
- **`css/style.css`**: 홈페이지의 색상, 폰트, 레이아웃 등 디자인을 담당합니다.
- **`js/animation.js`**: 스크롤 애니메이션 등 역동적인 기능을 담당합니다.
- **`images/`**: 모든 그림과 로고 파일이 들어있습니다.
    - **팁**: 새 이미지를 넣을 때는 가급적 파일명을 영어로, 의미가 통하게(예: `icon_email.png`) 지어주세요.

## 🛠 도움말 및 문제 해결
- **로그인 팝업**: 푸시할 때 로그인 창이 뜨면 `goodchoisillustration-create` 계정 정보를 입력하세요.
- **반영 지연**: 푸시 후에도 사이트가 바뀌지 않는다면 대략 5분 정도 기다린 후 브라우저의 강력 새로고침(Cmd + Shift + R)을 시도해 보세요.
